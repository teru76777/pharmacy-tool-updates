## 藥車標籤列印（HIS 擴充）v2.10.0

[下載安裝包](downloads/cart-labels-his-v2.10.0.zip) · [使用說明](standalone-extensions/cart-labels-his/extension/README.txt)

以管理版 2.9.1 為底，合併使用者本機版 2.9.3 的功能；沿用統一單字圖示「車」、電腦登記與工具內更新。

- 列印記憶只存日期、病房、床號、病歷號；空床只存病房、床號，不存姓名、生日。舊紀錄的生日在第一次開啟時自動刪除，比對不受影響。
- 可在「⚙ 設定 → 列印記憶」選一個本機資料夾，自動同步「列印記憶.txt」。用記事本修改後，下次開啟或按列印時套用；格式錯誤不套用也不覆蓋。檔案只寫在使用者電腦，不上傳 GitHub 或管理後台。
- 新增「列印記憶.txt」檢視頁；標籤工具頁首、設定、列印完成訊息與工具列彈出視窗都有連結。
- 版面改為米白底、陶土色按鈕；印出的標籤內容與排版不變。

已安裝 2.9.0／2.9.1：工具更新 → 檢查新版 → 更新並重新開啟，沒有新增權限。本機未含管理功能的 2.9.x：將 ZIP 的 extension 內容覆蓋原本載入的同一資料夾，重新載入後完成電腦登記。

驗證：以 2.9.1 更新核心檢核完整更新包（版本、權限、路徑、SHA-256）；在隔離 Chromium 以合成資料測試管理允許／未登記狀態、舊紀錄轉換、TXT 同步與列印記錄流程，列印畫面與 2.9.1 逐點比對一致（僅頁尾時間不同）。尚未在院內 HIS、實際資料夾授權或實體印表機驗證。

## 發布給管理後台的工具索引

後台透過公開的 [updates/catalog.json](updates/catalog.json) 找到工具，再直接讀取各工具的 latest.json 比對最新版，不需要 GitHub Token。

**新增或移除工具時，發布者必須一併更新工具索引**：於儲存庫執行 `python3 scripts/update-catalog.py`，把產生的 `updates/catalog.json` 與新工具一起發布。既有工具改版也建議重新產生索引以更新下載連結；未重新產生時，後台仍會讀取最新版本，但不會把舊版安裝包誤標為新版。

這個流程不授予 GitHub Actions 自動寫入 main 的權限。詳細格式與維護方式見 [索引說明](updates/CATALOG.md)。
